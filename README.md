A regulation comparison project designed to help reviewers map regulatory amendments to internal policies and prepare revision suggestions for human review.

**Project stack:** Vue 3, Node.js / Express, ChromaDB, Gemini API

## Research

### Multimodal Recommendation with Knowledge Graphs & GNNs

My master's research explored rating prediction with sparse interaction data by combining ratings, review text, and product images.

- Used LLMs and VLMs to extract information from reviews and images, alongside SBERT and CLIP embeddings
- Built a heterogeneous knowledge graph and applied GraphSAGE for rating prediction
- Evaluated seven modality configurations across four Amazon product domains using MAE and statistical tests
